## API 数据范围
- `https://api.openalex.org/institutions`：学校机构名、别名、国家、官网和研究指标，**不是专业招生数据库**。网页每个项目卡可按需查询 OpenAlex，并给出原始 API 链接；误匹配须核对。
- `https://api.frankfurter.dev/`：参考外汇换算（独立于招生信息）。
- `https://countries.dev/`：国家与货币/语言辅助信息（独立于招生信息）。
