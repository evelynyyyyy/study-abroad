# 词条与释义质量建设：第一阶段（2026-11-19）

本文件记录可验证的实现范围，不代表人工母语审校已完成。

## 已实现
- `lexicon-quality.js` 使用 `ko:<Unicode code points>:<sense index>` 给 8 个示例同形词建立 18 个独立的候选义项 ID（眼睛/雪、肚子/船/梨、夜晚/栗子、话/马、茶/车、写/使用/苦、乘坐/燃烧、苹果/道歉）。这是候选建模，**未被人工审核**；并未把这些候选义项全部扩展为可单独排程的学习卡。
- 旧记录的 `topik_lab_v2` 韩语词形键保持不变。新元数据仅作旁路补充，不会重写既有双向 Typing 或学习历史。
- 11 个词典原形、共 19 个明确列举的常见变形映射；不自动推导未列举的不规则活用，不把变形当作新增独立词汇。
- 中文题目在不同韩语词条具有**完全一致的中文核心释义**时可接受另一答案；没有扩大到模糊包含匹配，以免误判同形异义。
- 拼写错误如果恰好是词库中的另一个韩语词形，会在 `state.confusions` 记录实际混淆词对；只有一个音节相同并不会建立语义关联。
- 新词避让采用编辑距离为 1 的拼写近似判定；只影响首次认识，不覆盖已到期的复习调度。
- 所有候选释义的审核状态均为 `needs-human-review`。未验证的发音、例句、搭配、等级来源保持空值。未把 AI 提议或已有第三方翻译写成“人工审核通过”。

## 待办与限制
- 目前全词库仍是按韩语词形去重的学习卡；没有实现完整义项独立卡片、每义项独立记忆状态及无损迁移。含同形异义词的旧卡仍需拆分及题目语境提示。
- 词库中多中文释义和相近中文答案尚未逐一审查。上面的示例仅是数据结构与回归测试的种子，不是经过词典交叉验证的正式词义。
- 当前可核验的**人工审核通过数为 0**；新增 160 条仍为待人工审核。词库其余翻译未有逐条人工审核记录，不能把它们算成已审。
- 官方韩国语教育标准课程的逐词映射、真实语料频率、TOPIK 相关性、词性、标准音标、母语者例句、搭配及高级词汇处理尚待建设。
- 没有真实 iPhone Safari 设备测试；自动化测试只验证数据模型和调度行为，不等于语音质量、长时间内存或输入法实测。
- 新元数据的 `source: editorial-example` 表示待校对的建模示例，并不代表有外部词典出处。正式导入必须保留源 URL、许可、词典义项标识和校对记录。
