# 大规模词库来源与许可

网站名称：**TOPIK单词**。

## 2026-11 词库扩充

本网站额外纳入了 **Open Yonsei Korean Vocabulary** 项目中的 4,445 条韩语—简体中文词汇及表达记录（原始数据的六册总记录数），经与本站现有词条按韩语表面形式去重后展示。**去重会合并同形异义词，因此实际可学习的唯一词形数小于原始记录数。**

- 数据项目：https://github.com/sugalhjk-tech/yonsei-korean-vocabulary
- 建议署名：Open Yonsei Korean Vocabulary contributors, “Open Yonsei Korean Vocabulary dataset”, version 0.1.0, CC BY-SA 3.0.
- 数据许可：https://creativecommons.org/licenses/by-sa/3.0/
- 项目原始许可：https://github.com/sugalhjk-tech/yonsei-korean-vocabulary/blob/main/LICENSE.md
- 来源与第三方说明：https://github.com/sugalhjk-tech/yonsei-korean-vocabulary/blob/main/SOURCES.md

**本网站所做修改：** 从原始 CSV 选择册次、韩文词形、中文释义，转换为分册的精简 JavaScript 数据；用册次 1—6 作为本站的**教学分组**。此分组不是 TOPIK 官方 1—6 级词表，也不是官方 TOPIK 分级对应。保留原始词汇资料的适用署名、同方式共享许可及第三方条款。

原项目对 1,580 条记录标记了 `low` 复核置信度，其他记录也可能有错误。本站此次导入全部词条以便浏览和练习，**没有逐词人工审校**，用户输入中文的同义答案也可能无法被精确匹配。

原始数据的知识产权及许可按上述原项目声明及其第三方来源条款执行；本站独立开发的界面和逻辑不因此自动宣称属于该词库的版权贡献。词汇数据的后续改编与再分发应遵守适用的 CC BY-SA 3.0 条款。

## TOPIK 考试要求参考

- 韩国国立国际教育院：https://www.niied.go.kr/web/niied/contents/niied_topik
- 韩国观光公社 TOPIK 说明：https://english1.visitkorea.or.kr/enu/AKR/AK_ENG_2_1_5.jsp

TOPIK I 对应 1—2 级（听力、阅读），TOPIK II 对应 3—6 级（听力、阅读、写作）。TOPIK 1 级约 800 基础词、2 级约 1,500—2,000 词是能力描述参考值，不是逐词官方考试词表。
