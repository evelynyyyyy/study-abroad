# 韩语发音测试与人工核验

版本：v2.0.2。固定入口：https://evelynyyyyy.github.io/study-abroad/k/

## 当前实现

浏览器原生 `SpeechSynthesis` + `ko-KR` 语音筛选；优先使用本机 `ko-KR` 声音。未发现韩语声音时提示安装，不静默使用英文/中文声音。正常语速 1.0，慢速 0.78；两者均为浏览器语速控制，不是专门生成的两份高质量音频。单词和例句使用相同语音控制器，每次播放先取消前一段音频。

**重要限制**：无法从 JavaScript 保证某个系统韩语声音遵循所有韩国标准发音规则，也无法确保所有设备/iOS 浏览器声音一致；更不能仅凭播放成功判断音质合格。用户设备上的母语者听辨验收仍然必要。

## 手动 iPhone Safari 验收

1. iPhone 设置中确认已下载/启用韩语系统语音；使用 Safari 打开固定入口。
2. 在新词卡点击「听发音」，确认只出现韩语声音；再点击「慢速」，检查是否可辨且无明显失真。
3. 在例句上分别播放正常/慢速，听句调与停顿是否自然。
4. 连续快速点击不同单词发音，确认前一个停止、不会叠音；切换页面再播放。
5. 用上表 7 条样本分别测试 iPhone Safari、桌面 Safari/Chrome；记录 iOS 版本、声音名称、音变错误和异常。
6. 没有韩语语音时应提示安装，不能朗读成中文或英文。

自动化测试只覆盖声音筛选、语言、速率、取消前音、样本文本传递。未在本开发环境执行真实 iPhone Safari 或母语者听辨。

## 第三方项目评估

- [MeloTTS](https://github.com/myshell-ai/MeloTTS)：支持韩语、MIT 代码许可证，但 Python 运行时不适合直接托管在静态 GitHub Pages；若未来离线预生成音频需单独确认模型许可、生成音频许可和音质。
- [Supertonic TTS](https://github.com/cskwork/supertonic-tts)：WebGPU/WASM 浏览器推理，韩语支持，模型约 380 MB；移动设备首次下载、内存和 WebAssembly 性能未经本项目实测，不适合作为当前无门槛默认引擎。应用代码 MIT，模型权重单独受 Supertone 许可约束。
- [SNAP Korean Frontend](https://github.com/snap-libs/snap_voice)：重点是韩语音变、数字读法、语境消歧和语音预处理；不是可直接取代浏览器语音的独立轻量 TTS 引擎。未集成第三方代码或服务。

若后续实际听辨证明系统语音不够标准，可在取得合适许可、核验音质和文件大小后，优先为常见词/例句**预生成并部署静态音频**，以获得跨设备一致的声音。
