# v3.1.0 iPhone Typing 输入说明

## 浏览器能力
- `lang="ko"` / `lang="zh-CN"` 用于标记输入语言，不保证 iOS 自动切换系统键盘。
- `inputmode="text"` 是系统文字键盘；`inputmode="none"` 用于网页韩语键盘模式，但硬件键盘、Safari 版本等可能影响表现。
- iOS Safari 对无用户手势的程序化 `focus()` 有限制；不反复强制弹出系统键盘。
- `autocomplete="off"`、`autocorrect="off"`、`autocapitalize="off"` 减少无关自动补全，但不控制键盘语言。

## 三种模式
- 系统键盘：完全使用系统原生输入。
- 智能输入（默认）：提供题目对应的 lang/inputmode 提示；不宣称自动切换输入法。
- 网页韩语键盘：仅中文→韩语题目使用内置两套式；韩语→中文继续系统输入。

## 两套式实现
`hangul-keyboard.js` 实现 Hangul Unicode L/V/T 音节合成，复合元音（ㅘ/ㅙ/ㅚ/ㅝ/ㅞ/ㅟ/ㅢ）、双收音（ㄳ/ㄵ/ㄶ/ㄺ/ㄻ/ㄼ/ㄽ/ㄾ/ㄿ/ㅀ/ㅄ）、双辅音、删除及选区/光标编辑。键盘显示辅音与元音，点击 ⇧ 可选择双辅音；不是罗马字拼写。输入框仍可复制粘贴和用硬件键盘编辑。

## 调度
同一方向题目仅在与最高优先级题目分差不超过 8 时可被优先选中。到期/遗忘分数和防止相邻重复仍优先，不改变复习到期时间。

## 验收
GitHub Actions 执行语法和合成测试；未获得真实 iPhone Safari 实机，因此不能声称实际设备已通过。建议实机验证：学生/먹었어요/값/과 等输入、连续切换、中文输入法组合、屏幕底部按钮、横竖屏和刷新恢复。
