# TOPIK单词

静态网页，部署于 GitHub Pages：<https://evelynyyyyy.github.io/study-abroad/topik-vocab/>

**网站名称为「TOPIK单词」。** 无需服务器、数据库或 npm 构建；入口为 `index.html`，界面样式在 `styles.css`，学习逻辑在 `app.js`，扩充词库在 `vocabulary.js`。

## 学习功能

- TOPIK 1—6 学习难度切换。原有示例词和补充词库之外，新增了 4,445 条来自开源《延世韩国语》词汇整理项目的韩中记录（网站按韩语词形去重，实际唯一词形数以页面显示为准），不是 TOPIK 官方分级词表，也不是完整的 TOPIK 1—6 词库。
- 自主学习：不设置每日新词数量或学习时长；统计已接触词与可选复习提醒。
- 学习新词：韩语、中文、罗马字拼读参考与已有例句直接显示，随时跳到下一词。
- 语境学词：在原创韩语练习短句中理解词义，可听整句朗读；目前仅覆盖有例句的部分词汇，暂不等同于影视真实语料。
- 复习自评：回忆后可选择“记住了 / 有点模糊 / 还没记住”；复习计划是可选的，无强制学习目标。
- 从学习页可直接对当前词进行中文释义或韩语拼写打字测试。
- 韩文拼写：中文 → 韩语，必须自己输入韩文并提交答案。
- 中文释义输入：韩语 → 中文，必须自己输入中文释义并提交答案；支持词条中用顿号、逗号或斜线分隔的多个简短义项。语义相近但措辞不同的答案可能被判错，请以显示的参考释义为准。
- 间隔复习：按单词及练习方向分别记录复习时间；初次复习间隔 10 分钟，然后 1 / 3 / 7 / 14 / 30 / 60 / 90 天。属于简单阶梯排程，**不是 FSRS 或经过个性化校准的记忆模型**。
- 错词强化、词汇收藏、韩语浏览器语音、精选短句及发音注释。
- 搜索、CSV 导入/导出、JSON 学习进度备份/恢复；所有数据保存在当前浏览器 localStorage，不能自动跨设备同步。

## 新词首次学习与双向 Typing

「学习新词」每轮最多选 10 个未学习或首次学习尚未完成的词；数量是**单词数**，不是两倍的题目数。流程如下：

1. **新词认识（未学习 → 已展示）**：韩文、中文、发音按钮、现有例句同时可见；点击下一词只记录「已展示」，不算 Typing 正确、不计为掌握，也不设置长复习间隔。
2. **初次回忆（已展示 → 学习中）**：先看完整批词，再把韩语 → 中文和中文 → 韩语两组 Typing 打乱穿插；两种方向分别记录成绩。
3. **错误强化**：答错后显示正确答案；在其他题目之后重试，每个词的每个方向最多增加两次重试，不会无限循环。
4. **复习中**：两个方向各至少完成一次输入作答（不要求第一次正确），才进入间隔复习；两方向有各自的 step、due、wrong。
5. **已掌握**：两个方向的记忆阶梯均达到 4 级后才认定掌握；之后答错可以降回「复习中」。

学习进度保存在浏览器的 `topik_lab_v2` 记录中，新增 `lifecycle` 字段；旧进度不清空。之前只有认词记录的词会按「已展示」迁移，不会错误标记为已掌握。中途退出时已展示状态保留，下次可以继续新词首次学习流程（当前轮的临时题目顺序不保存）。

## 语境学习改进

参考“不背单词”公开说明中的真实语境学习、拼写练习及根据记忆效果复习的**教学思路**，但不复制其软件界面、例句、音频或源码。新增 `study-context.js` 包含约 200 个原创教学短句（包含中文翻译），不是影视剧的正版原声例句；未经过独立母语审校。页面内允许听韩语单词及句子、从词义卡立即做当前词的双向打字练习。练习判分与记忆自评独立保存。

## 词库来源

新增分册词库放在 `data/yonsei-01.js` 至 `data/yonsei-06.js`，原始数据的署名、许可、第三方条款、审校局限及 TOPIK 分级说明见 [DATA-LICENSE.md](./DATA-LICENSE.md)。六册分组仅为学习路径，不等同官方 TOPIK 1—6 等级。网站没有每日学习目标或数量限制。

## 词库导入

CSV 的列名：`level,ko,zh,example,translation,reading`，后面三列可省略。支持符合 CSV 标准的带引号字段和逗号。导入时忽略已经存在的韩语词形。

## 设计原则与学习技能参考

并没有复制第三方项目的源码或词库，而是借鉴公开描述的学习机制：

- [HanCards](https://github.com/TeamBaconn/HanCards)：自定节奏的卡片、测验与间隔复习。
- [kor-srs](https://github.com/CorbinFoucart/kor-srs)：以词汇识别为先的记忆训练、结合语境。
- [korean-flashcards](https://github.com/niksavis/korean-flashcards)：浏览器韩语发音与分阶段练习。

详见 [SKILL.md](./SKILL.md) 的韩语词汇学习流程。

## 兼容性

使用浏览器 Web Speech API 朗读，语音质量和是否支持韩语受浏览器、设备安装的语音包影响。建议使用现代 Chromium / Safari / Firefox；拼写需启用韩语输入法。深浅色模式、键盘焦点、移动端导航以及降低动态效果均已实现。未进行独立的跨浏览器视觉人工验收。
