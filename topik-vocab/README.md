# 韩语词汇实验室 · TOPIK 1–6

这是适合手机端的纯 HTML 单页韩语单词练习工具，无需构建流程。

## 使用

直接打开 `index.html`。部署时将 `topik-vocab` 目录作为静态网页根目录。支持认词卡、拼写训练、间隔复习、浏览器发音、搜索和导入 CSV 词库，以及本地学习进度备份和恢复。

## 词库

自带 104 个左右精选示例词，按学习难度分配到 TOPIK 1–6 六档；这些是教学用难度分组，**不是 TOPIK 官方分级词表，也不是覆盖全部考纲的完整词库**。可导入自己的 CSV 增补。CSV 首行字段：`level,ko,zh,example,translation`；level 为 1 至 6。

## 记录

进度保存在浏览器 localStorage 中，不会跨设备同步。请定期在词汇列表页导出备份。
