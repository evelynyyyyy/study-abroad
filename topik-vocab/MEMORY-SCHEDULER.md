# v3.0.0 — 记忆巩固算法与迁移说明

本版本是受 FSRS 记忆稳定度/难度/保持率启发的自定义调度器，**不是官方 FSRS 参数或完整 FSRS 实现**。

## 记忆阶段
- 未学习：无展示或答题记录
- 初次认识：看过韩语和中文，尚未主动回忆
- 初步记忆：至少有一个方向尝试回忆，另一方向尚未完成
- 巩固中：双向已回忆，仍需完成分钟级步骤或跨日复习
- 长期复习：两个方向均进入间隔复习、稳定度至少 7 天、各有跨日成功，当前预测保持率至少 80%
- 熟练掌握：两个方向分别至少 4 次 v3 主动成功、各至少 2 次不同日期成功、稳定度各至少 21 天、当前预测保持率至少 85%，并且遗忘后至少隔一天再次验证。即使达到该阶段，仍按到期日复习；状态可因遗忘或长期未复习下降。

## 时间安排
每个方向独立：新词成功后约 3 分钟、15 分钟、3 小时，然后次日；答错/不知道进入独立的 3/15/180 分钟重新巩固。Hard/Good/Easy 仅对答对生效；Again 对错误/不知道生效。达到长期复习后以预测保持率、稳定度、难度与反馈调整间隔；以上步骤和阈值均位于 `TOPIK_SMART.CONFIG`。

## 旧数据保护
- 不更换 `localStorage` 键 `topik_lab_v2`，不清空 `progress`、`daily`、`smartAnswerHistory`、`lifecycle`。
- 旧 `step`、`correct`、`memory.stability` 不能证明跨日成功；v3 只认可带 `schedulerVersion:3` 的后续主动回忆证据。
- 旧方向的到期日可能被安排得过远；`due()` 将未迁移的方向视为待巩固，并在用户真正作答时惰性建立 v3 记忆记录。
- 历史正确/错误总次数继续保留，但不伪造跨日成功次数。无法判明的词保守降为巩固中。
- “还不熟悉”与主动重新学习会保留答题历史，同时重启对应方向的短期巩固。
- 现有自定义词库、双向 Typing、固定网址、同源短链接、备份导入导出均保留。

## 验证限制
Node 回归测试模拟分钟级、次日、错误方向、重开浏览器后的 JSON 恢复和旧进度。没有真实 iPhone Safari 实机测试，也没有经过真实用户记忆数据校准；调度参数属于初始教学默认值，需要后续评估。
